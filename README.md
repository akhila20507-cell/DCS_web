# PACELINE

A responsive running and sportswear website developed as part of the DCS Web Cluster / Frontend Task.

## Features

- Responsive design for desktop, tablet and mobile
- Home and About pages
- Interactive product category filters
- Favourite buttons
- Responsive navigation
- New arrivals section
- Our Story section
- Men's and Women's running sections
- Newsletter section
- Accessible image alt text
- Mobile-friendly layouts

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub
